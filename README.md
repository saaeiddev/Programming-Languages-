# Programming Languages Café ☕💻

An immersive interactive 3D café for exploring programming languages.

## Experience

- Real-time Three.js café environment
- Interactive animated laptop and cinematic camera focus
- 12 clickable programming-language cards with Persian explanations
- Devicon language artwork on 3D cards
- High-quality glTF sample props from Khronos glTF Sample Assets
- Procedural coffee steam, atmospheric particles, neon art and dynamic lighting
- Generative light ambient music using Web Audio API
- Responsive desktop/mobile interface
- GitHub Pages deployment workflow
